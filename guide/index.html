About Download Features FAQ Guide

Downloading

First, you have to download Java as Currently Techno Launcher doesn't automatically install java. This is the Official Java Download Page.

  1. Go to Official Java Download Page.

  2. Select Windows-64 bit Installer.

  3. Double-click the download .exe file from the Downloads folder.

  4. Click Next, select the java installation path and click Install.

  5. Click Close, When the Installation is complete.

Now, you have the java. It's turn to Install Techno Launcher:

  1. Go to Techno Launcher Official Download Page.

  2. Click on Download Button.

  3. Double-click the download .exe file from your Downloads folder.

  4. Click Next, Select the Techno Launcher installation path and click Install.

  5. Click on Finish, after the installation is complete.

Now, you can access Techno Launcher from your dekstop shortcut or from start menu.

Installing Version

  1. Launch Techno Launcher

  2. Type any version you want in the Text Box next to Install Vanilla button

  3. Click on which loader do you want: Vanilla, Forge, Fabric.

  4. Techno Launcher freezes until your installation is complete.

  5. Your version will be showed in the Installed Versions section.

Launching Minecraft

  1. Select your minecraft directory folder in minecraft directory section (Recommended default).

  2. Select your RAM allocation through the slider (default: 2560 MB).

  3. Select your username in the Username text box.

  4. Choose your version on Installed Version Section

  5. Click on Launch button.

Installing Mods

Installing Modrinth Mods (Fabric and Forge only)

There is an In-Built Mod manager. So, you don't have to go to download any mods on modrinth. But, this only supports mods for Fabric and Forge on modrinth.

  1. Type your mod name in the text box of Mod Manager.

  2. Select your loader.

  3. Choose your minecraft version.

  4. Click on Get Mod button.

Installing Other Mod Hosting Platforms

Since, currently Techno Launcher In-Built mod manager can't install CurseForge or other platforms mod; You have to download them manually.

  1. Download your .jar file from any platform like CurseForge or modrinth.

  2. Click on Import Mods(.jar).

You can disable/enable or delete any mods from In-Built Mod Manager.

To Add Worlds

  1. Click on Import Worlds button.

  2. Open your world folder.

    3. Your worlds will be shown at the bottom of the worlds list.

Switching Theme

  1. Locate the dropdown at the top of the launcher.

  2. Choose any theme from the dropdown: System, Light or Dark.
